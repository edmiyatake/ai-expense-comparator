# Project Structure

- `/expense_comparator`
    - `/models`
        - `expense.py` &mdash; Defines the Expense ORM model with fields and relationships.
        - `category.py` &mdash; Defines the Category ORM model, including mapped keywords.
        - `recurring_pattern.py` &mdash; Defines the RecurringPattern ORM model for recurring expense grouping.
        - `import_log.py` &mdash; Defines the ImportLog ORM model for logging each import operation.
        - `__init__.py` &mdash; Imports all model classes for ORM registration.
    - `/managers`
        - `expense_manager.py` &mdash; Handles CRUD operations and CSV import for expenses.
        - `category_manager.py` &mdash; Manages category CRUD, mapping, and keyword association.
        - `comparison_engine.py` &mdash; Provides aggregation and analytical comparisons of expenses.
        - `recurring_detection.py` &mdash; Implements recurring expense detection logic and flagging.
        - `insights_engine.py` &mdash; Analyzes expenses to generate insights, trends, and anomaly reports.
        - `import_logger.py` &mdash; Records details and status of import operations.
        - `__init__.py` &mdash; Exposes manager interfaces to other modules.
    - `/visualizations`
        - `charts.py` &mdash; Renders breakdown, trend, and comparison charts for CLI or API output.
        - `__init__.py` &mdash; Exposes visualization utilities.
    - `/cli`
        - `main_cli.py` &mdash; Entrypoint for the command-line interface.
        - `prompts.py` &mdash; Handles CLI prompts, input validation, and formatting.
        - `__init__.py` &mdash; CLI module setup.
    - `/api`
        - `main_api.py` &mdash; Entrypoint for the web or REST API server.
        - `endpoints.py` &mdash; Defines API routes and handlers for domain resources and reports.
        - `__init__.py` &mdash; API module setup.
    - `/db`
        - `init_db.py` &mdash; Sets up the database schema and manages migrations.
        - `__init__.py` &mdash; DB module setup.
    - `/tests`
        - `test_expense_manager.py` &mdash; Unit tests for expense CRUD, queries, and import logic.
        - `test_category_manager.py` &mdash; Tests for category operations and mappings.
        - `test_comparison_engine.py` &mdash; Tests for comparison and aggregation routines.
        - `test_recurring_detection.py` &mdash; Tests recurring expense identification.
        - `test_insights_engine.py` &mdash; Tests for insights, anomaly, and trend generation.
        - `test_import_logger.py` &mdash; Tests logging and error handling for imports.
        - `test_charts.py` &mdash; Tests chart output and data structure correctness.
        - `integration_tests.py` &mdash; End-to-end tests covering cross-module workflows and persistence.
        - `__init__.py` &mdash; Test module initialization.
    - `orchestrator.py` &mdash; Coordinates flows between managers, agents, CLI/API, and visualizations.
    - `config.py` &mdash; Global configuration, environment variable loading, and runtime options.
    - `README.md` &mdash; Project overview, setup, and usage instructions.
